# JPG to PNG Converter

A browser-based JPG to PNG converter built with React, TypeScript, and Tailwind CSS.

All image processing happens locally in the browser using the Canvas API.

## Features

* JPG to PNG conversion
* Batch image conversion
* ZIP download support
* Multiple image uploads
* File validation and limits
* Responsive UI
* Browser-only processing

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* JSZip
* Vite

## Installation

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
